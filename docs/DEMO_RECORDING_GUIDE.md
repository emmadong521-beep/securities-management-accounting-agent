# Demo Recording Guide

## Recommended 30-60 Second GIF Flow

1. Open the Streamlit app.
2. Select period `2025-09`.
3. Open CFO dashboard.
4. Open PVM analysis.
5. Open high-revenue low-profit branch analysis.
6. Run What-if simulation.
7. Open Agent Workbench.
8. Submit sample task:
   “请分析 2025-09 公司利润低于预算的主要原因。”
9. Show final business conclusion.
