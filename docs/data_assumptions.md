# 数据假设

本项目仅用于个人学习和求职作品集，不代表真实长江证券内部数据，不构成投资建议。

## 来自审计报告公开披露的数据

使用营业总收入、手续费及佣金净收入、业务及管理费、净利润、经纪业务、投行业务、资管业务、自营业务、融资融券利息收入等公开披露汇总指标做规模校准。

## 合成数据

月度预算、月度实际、经纪 KPI、营业部费用、利润贡献、PVM 拆解、管理洞察均为合成数据。金额单位为人民币元，展示层可换算万元。

## 业务线拆分假设

经纪业务使用证券经纪业务净收入校准；信用业务使用融资融券业务利息收入校准；自营业务使用证券自营分部收入校准；财富管理按代销金融产品收入做合理放大。

## 费用分摊假设

管理会计口径把直接成本和分摊费用分别建模。上海营业部因高频客户占比高，被分摊更多 IT 系统成本和总部管理成本。

## 异常和经营故事

内置经纪低于预算、上海高收入低利润率、财富管理收入增长但利润贡献不足、信用业务收入低于预算、营业部表面高收入但分摊后利润不高等故事。

## 合规说明

不包含任何未公开重大信息、客户隐私数据或商业秘密。审计报告只用于公开披露汇总口径校准，明细全部合成。
