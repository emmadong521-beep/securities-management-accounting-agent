# 项目说明

## 业务价值

本项目面向证券公司管理会计分析场景，模拟 CFO 月度经营分析、业务线利润贡献、营业部盈利能力、经纪业务 PVM 差异拆解和管理洞察生成。

## 技术实现

- 使用 Python、pandas 和 DuckDB 构建预算、实际、KPI、费用分摊和利润贡献数据链路。
- 将经纪业务 PVM 拆解扩展到期间、营业部、客户分层和产品类型。
- 使用 Streamlit 和 Plotly 提供可交互经营看板和自动经营分析报告。

## 后续扩展

- 对接月结确认后的实际收入和费用分摊数据。
- 增加产品、客户经理、渠道、投行项目等管理维度。
- 引入 LLM 生成更自然的管理建议，但所有金额仍由代码计算。
