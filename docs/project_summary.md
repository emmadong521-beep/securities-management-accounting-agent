# 项目说明

## 业务价值

本项目面向证券公司管理会计分析场景，模拟 CFO 月度经营分析、业务线利润贡献、营业部盈利能力、经纪业务 PVM 差异拆解和管理洞察生成。

## 技术实现

- 使用 Python、pandas 和 DuckDB 构建预算、实际、KPI、费用分摊和利润贡献数据链路。
- 将经纪业务 PVM 拆解扩展到期间、营业部、客户分层和产品类型。
- 新增 deterministic mock Agent 层，将自然语言任务解析为计划，并真实调用盈利能力、预算差异、PVM 和经营洞察工具。
- 使用 Streamlit 和 Plotly 提供可交互经营看板和自动经营分析报告。

## Agent 层能力

- 支持分析公司利润低于预算的主要原因。
- 支持拆解经纪业务收入低于预算是交易量影响还是佣金率影响。
- 支持分析营业部收入排名与经营利润率之间的差异。
- 展示用户任务、计划、工具调用轨迹、观察结果、最终经营结论、关联图表和追问回答。
- 预留 LLM API 扩展点，金额和分析口径仍由代码计算。

## 后续扩展

- 对接月结确认后的实际收入和费用分摊数据。
- 增加产品、客户经理、渠道、投行项目等管理维度。
- 引入 LLM 生成更自然的管理建议，但所有金额仍由代码计算。
