# Changelog

## v0.1.0

Initial securities finance AI PoC release.

### Added

- Synthetic securities management accounting data.
- Business-line profitability.
- Brokerage PVM analysis.
- Branch profitability.
- High-revenue low-profit analysis.
- What-if simulation.
- Deterministic Agent Mode + Optional LLM Enhancement.
- CFO-style report generation.
- Data quality report.
- GitHub Actions CI and coverage.

### Notes

- Detailed transaction, voucher, branch, customer, and operating data is
  synthetic.
- LLM is optional and does not perform financial calculation.
